● I added a big Jump button below the Pete game field. It only shows on touch
  devices, using the same check that already shows the pause button, so desktop
  doesn't change. I checked that game.js has no syntax errors, but I haven't
  tried it in a browser or on a phone yet.

  How it works (pete/game.js)
  - Holding to jump higher works the same way: pressing the button starts the
    jump and lifting your finger ends it, just like tapping the field.
  - It also starts and resumes the game, the same way Space does on desktop. On
    the Ready, Mashed, or Paused screens, pressing Jump starts or resumes a run.
  - Tapping the field still jumps too, so players can use either one.
  - Long-presses won't get in the way: holding the button won't open the copy
    menu or zoom the page.
  - It stays on screen: when a run starts, the page already scrolls the game
    field into view, and now it also scrolls so the Jump button is visible.

  Look (style.css): a yukon-gold pill with a russet border, matching the overlay
  buttons. It's 64px tall and up to 360px wide, with a russet-dark shadow that
  presses down when tapped.

  Page (pete/index.html): the touch hint now says "Tap Jump (or the field) to
  jump." I bumped the cache versions to style.css?v=5 and game.js?v=6 on the
  Pete page so phones load the new files. The home and Catch pages still point
  at style.css?v=4. They'll pick up the new CSS once their cache expires, which
  doesn't matter because the new styles only affect the Pete page.

  Together the changes add about 2KB, so the site is still well under 512KB.
  Nothing is committed yet.
