# Bill's Potato Shack

This repository is a simple static website to act as an experience for
billspotatoshack.com in DNS.

It is intended to be a goofy/parody storefront for a merchant that only
sells potatoes.

## Technical Details

#### Static

This site is inherently not intended to be dynamic, or loading any extra data. Consequently,
its repository should be comprised of only HTML, CSS, and JavaScript for any extra client-side behavior.

#### 512kb Club

This site should strive to be part of the [512kb club](https://512kb.club/) someday.

As a result, its initial payload and subsequent client-side loads should remain to be under
512kb in size, leaving the end user with a seamless experience.

## Design

The design should be extremely potato-oriented. The initial version of the site should be a single page.
The center of the page should contain a CSS-based image of a yukon gold potato. The colors of the site should
be based on the hex values of a yukon gold and russet potato skins.

There can be a single anchor to bounce to a section of th page for:
- "About" - a small blurb about how a small, family operation runs Bill's Potato Shack and is proud of their quality
